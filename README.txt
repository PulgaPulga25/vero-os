VERO OS v2
Prototipo local gamificado.
Incluye XP, niveles, rangos, logros, módulos bloqueados, biblioteca, registro de hábitos, más de 200 misiones de enfoque y más de 100 ideas antiaburrimiento, con anti-repetición.
Abre index.html para probar.
NOTA: el bloqueo real de apps Android todavía debe conectarse a una automatización/app con permisos del sistema. No es técnicamente posible que una página web bloquee Instagram/Facebook por sí sola.
El progreso actual se guarda en localStorage; antes del uso definitivo conviene añadir respaldo/exportación o almacenamiento persistente.

V3: Reemplaza los emojis de las tarjetas por seis ilustraciones CSS animadas: teléfono/candado, medidor, cartas, libros, carpeta classified y sobre top secret.

V4 SOUND:
- Web Audio sound engine, generated entirely in the browser.
- UI click, panel open/close, digital lock, mission transmission, reroll, mission complete, XP/archive, achievement, denied access, secret module and boot sounds.
- SFX on/off and master volume are saved locally.
- Modern mobile browsers require the first tap before audio is allowed; after that, VERO OS can play its UI sounds normally.

V4.1 Chrome audio fix: explicit user-gesture audio initialization gate, AudioContext resume, silent-buffer priming, and louder test sequence.
